# Flow Logic Patterns (Логически Модели)

> [!IMPORTANT] AI INSTRUCTION
> Use this guide to explain how to connect blocks to create actual logic (Loops, If-Else).

## 1. IF-ELSE Разклонение
Използвайте блока **Condition (IF)**, за да разделите пътя на две.

- **Структура:**
    - Вход -> IF Блок
    - **TRUE Pin** (Зелен) -> Свържете към действията, ако е ВЯРНО.
    - **FALSE Pin** (Червен) -> Свържете към действията, ако е ГРЕШНО (или директно към следващия етап, ако няма else).
- **Merge:** Двете пътеки могат да се съберат отново по-надолу (напр. в общ END блок или следваща стъпка).

## 2. Създаване на Цикъл (Loop)
Циклите в Flow Editor изисква **изрично затваряне** на кръга.

**Стъпки:**
1.  Добавете блок **Loop**.
2.  Свържете **BODY Pin** (Дясна стрелка) към първото действие в цикъла.
3.  Наредете действията в цикъла.
4.  **ВАЖНО:** На края на веригата от действия, сложете блок **Flow Control** с тип `LOOP_BACK`.
    - В настройките на `LOOP_BACK` изберете целевия Loop блок ("Target Label").
5.  Свържете **EXIT Pin** (Долна стрелка) на Loop блока към това, което следва, след като цикълът приключи.

*Без `LOOP_BACK`, цикълът ще се изпълни само веднъж!*

## 3. Използване на Етикети (Labels & Jumps)
Ако линиите станат твърде заплетени, използвайте "Безжични връзки" чрез Jumps.

1.  **Сложете Котва:** Добавете `Flow Control` -> тип `LABEL` на мястото, където искате да отидете. Дайте му име (напр. "Emergency_Stop").
2.  **Сложете Скок:** На друго място добавете `Flow Control` -> тип `GOTO`.
3.  **Настройте:** В `GOTO` блока изберете "Target Label" -> "Emergency_Stop".

Системата автоматично ще премести изпълнението от GOTO към LABEL, без да чертаете дълга линия през целия екран.
