# Flow Variables Guide (Ръководство за Променливи)

> [!IMPORTANT] AI INSTRUCTION
> Use this guide to explain how to store data, use dynamic values, and understand scope.

## Какво са променливите?
Променливите са "паметта" на вашия Flow. Те съхраняват стойности (числа, текст), които могат да се променят по време на изпълнение.

### Типове (Data Types)
- **Number:** Числа (напр. `25.5`, `100`). Поддържа десетични запетаи.
- **String:** Текст (напр. "Error", "System Ready").
- **Boolean:** Истина/Лъжа (`true`/`false`).

### Обхват (Scope)
Има два вида променливи според това къде се виждат:

1.  **Local (Локални):**
    - Видими САМО вътре в текущия Flow.
    - Използват се за временни сметки (напр. `Current_EC`, `Loop_Counter`).
    - Изчезват, когато Flow приключи.

2.  **Global (Глобални):**
    - Видими за потребителя при стартиране на програмата.
    - Използват се за **Входни параметри** (напр. `Target_PH`, `Dose_Amount`).
    - Потребителят може да ги променя, преди да пусне Flow.

---

## Динамични Стойности (Syntax)

За да използвате стойността на променлива вътре в блок (напр. в IF условие или LOG съобщение), използвайте синтаксиса с двойни къдрави скоби:

`{{variable_name}}`

**Примери:**
- В LOG блок: `"Текущото pH е {{ph_val}}"` -> `"Текущото pH е 6.2"`
- В IF блок:
    - Left: `{{current_ec}}`
    - Operator: `<`
    - Right: `{{target_ec}}`
- В Actuator DOSE:
    - Amount: `{{dose_ml}}` (вместо твърдо число 50).

---

## Variable Manager (Управление)

Натиснете бутона **Variable Manager** в горната лента, за да:
- **Add Local Var:** Добавяте нова вътрешна променлива.
- **Global:** Виждате входните параметри.
- **Unit:** Можете да зададете мерна единица (напр. `ml`, `sec`, `pH`), която помага за яснота в интерфейса.
