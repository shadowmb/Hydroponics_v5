# Basic Programs (Графици)

> [!IMPORTANT] AI INSTRUCTION
> Use this guide when user asks about "Daily Schedule" or simple time-based tasks.

Basic режимът е списък от задачи, подредени по час.

## Структура на Събитие (Event)
Всяко събитие има:
1.  **Time (Час):** Кога да се случи (напр. `08:00`).
2.  **Steps (Стъпки):** Списък от **Потоци (Flows)**, които да се изпълнят последователно.
    - Стъпка 1: "Напълни резервоара"
    - Стъпка 2: "Разбъркай"
    - Стъпка 3: "Полей"

## Auto-Fix (Автоматична Подредба)
Бутонът **Auto-Fix** е много полезен помощник.
- Ако имате зададен **Min Interval** от 60 минути.
- И добавите събития хаотично (напр. едно в 08:00 и следващото в 08:15).
- Натискането на **Auto-Fix** автоматично ще премести второто събитие на 09:00, за да спази интервала.

## Съвети
- Basic програмите се повтарят всеки ден (Daily Schedule).
- Ако искате нещо да се случва само веднъж или при условие, ползвайте **Advanced Mode**.
