---
description: Изготвяне на commit на промените и пеценка за нов бранч
---

Искам да запазя текущите промени. Моля:
1. Анализирай промените (`git status`/`diff`) и текущия бранч (`git branch --show-current`).
2. ПРЕЦЕНИ контекста:
   - Ако промените съответстват логически на текущия бранч -> Продължи в него.
   - Ако са за различна тема/задача -> Създай нов бранч с подходящо име (напр. `feat/...` или `fix/...`) и премини в него.
3. Генерирай професионално Commit съобщение (Conventional Commits: `feat`, `fix`, `docs`, `chore`) на английски.
4. Изпълни `git add`, `git commit` и `git push` (вкл. `--set-upstream` ако е нов бранч).
